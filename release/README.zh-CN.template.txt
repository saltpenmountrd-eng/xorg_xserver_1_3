====================================================================
PenMount USB 触摸屏 Xorg 驱动套件
====================================================================

打包版本   : @PACKAGE_VERSION@
打包日期   : @BUILD_DATE@
驱动版本   : xf86-input-penmount @DRIVER_VERSION@
定位程序版本: pm_calibrate @CALIBRATE_VERSION@

本套件适用的触摸屏: PenMount USB(USB vendor 0x14e1 / product 0x6000)


--------------------------------------------------------------------
一、套件内容
--------------------------------------------------------------------

  penmount_drv.so     Xorg 输入驱动本体(fork 自 xf86-input-evdev 1.1.5,
                       与 xorg-server 1.3.0.0 的 XInput ABI 兼容)
  pm_calibrate         GTK2 图形化触摸屏校准程序
  penmount-setup.sh    安装/卸载脚本(本文件即为其简体中文说明)
  README.txt           本说明文件


--------------------------------------------------------------------
二、系统需求
--------------------------------------------------------------------

  - xorg-server 1.3.0.0(或 XInput ABI 相同、即 ABI_XINPUT_VERSION 0.7
    的版本);penmount_drv.so 是针对这个 ABI 编译的模块,不保证能在其
    他版本的 Xorg 上加载。
  - pm_calibrate 运行时需要:GTK2(libgtk-x11-2.0)、X11 核心函式库
    (libX11)、经典 XInput 1.0 客户端函式库(libXi)。这些是运行期
    依赖,若目标机器上没有安装对应的运行期函式库,pm_calibrate 会无
    法启动。
  - 需要有系统管理员(root)权限执行安装/卸载脚本,以及编辑
    /etc/X11/xorg.conf、写入 Xorg 的 input 模块目录。


--------------------------------------------------------------------
三、安装方式
--------------------------------------------------------------------

  1. 以 root 权限执行:

       ./penmount-setup.sh install

     这个脚本会自动完成:
       - 把 penmount_drv.so 复制到 Xorg 的 input 模块目录
         (/usr/lib/xorg/modules/input 或 /usr/lib64/xorg/modules/input)
       - 在 /etc/X11/xorg.conf 的 ServerLayout 区段加入(或取消注释)
         PenMount 这一行 InputDevice 设置
       - 在 /etc/X11/xorg.conf 加入 PenMount 的 InputDevice 区段
         (Driver "penmount",并预设锁定 vendor 0x14e1 / product 0x6000,
         Debug 选项预设为 "off")

     每次修改 xorg.conf 前都会自动备份一份带时间戳的原始文件,備份檔
     跟 xorg.conf 放在同一目录下。

  2. 安装完成后,请重新启动系统以套用变更。

  【重要】如果 penmount_drv.so 已经安装过(模块目录下已存在该文件),
  penmount-setup.sh install 会直接拒绝执行并报错。这是有意的保护机
  制——如果 Xorg 已经加载过旧版本的驱动,直接覆盖模块文件有可能导致
  正在运行的 X 不稳定甚至崩溃。若要更新驱动版本,请依照下列顺序操作:

       ./penmount-setup.sh uninstall
       (重新启动系统)
       ./penmount-setup.sh install


--------------------------------------------------------------------
四、卸载方式
--------------------------------------------------------------------

  以 root 权限执行:

       ./penmount-setup.sh uninstall

  会移除 /etc/X11/xorg.conf 中 PenMount 相关的所有设置,以及模块目录
  下的 penmount_drv.so。卸载完成后,请重新启动系统,再执行 install
  安装新版本(不要在同一次开机期间内直接重新安装)。


--------------------------------------------------------------------
五、触摸屏校准
--------------------------------------------------------------------

  安装完成、重启系统并确认触摸屏被正确识别之后,以一般使用者或 root
  身份在 X 环境下执行:

       ./pm_calibrate

  预设为 9 点校准,可用 --points 4 改成 4 点校准(未来也支援 16、25
  点)。校准流程:

    1. 程序会以全屏黑底白色十字准心依序显示各个校准点,画面上方会
       同时显示目前进度以及「ESC 键中止」的提示。
    2. 依序触摸每一个十字准心。
    3. 全部触摸完成后,程序会自动计算校准矩阵,写入
       /etc/penmount/CalibData,并通知驱动重新加载,不需要重启 X。
    4. 若中途按 ESC 键,会直接中止,不会更动既有的校准数据(保留上
       一次的有效校准)。

  校准过程中使用到的临时文件(全部位于 /etc/penmount/ 目录下):

       CalibStart   校准程序执行期间存在,驱动侦测到此文件会暂停套用
                    既有校准、改为回报原始触摸座标,方便校准程序取样
       CalibOK      校准完成后建立,驱动侦测到后会重新加载校准数据,
                    并自行删除此文件
       CalibData    实际的校准矩阵数据(二进位格式,带 CRC32 校验)

  如果需要在命令行下查看驱动的运行状态,可以查看 Xorg 的 log 文件
  (一般在 /var/log/Xorg.0.log),驱动的相关信息都会以
  "PenMount-..." 开头的行输出。


--------------------------------------------------------------------
六、疑难排解
--------------------------------------------------------------------

  - 如果 X 启动后触摸屏完全没有反应,请先确认:
      1. lsusb 能不能看到 vendor 0x14e1 / product 0x6000 的装置
      2. /etc/X11/xorg.conf 里 PenMount 的设置是否存在且没有被注释
      3. Xorg 的 log 文件里有没有 "PenMount" 相关的错误信息

  - 如果校准结果偏移很大或完全不对,请重新执行一次 pm_calibrate,
    校准时每一点务必确实触摸到十字准心中心,并稍微停留、避免过快
    松手。

  - 如果需要重新安装或更新驱动版本,请务必按照第三节所述的
    uninstall → 重启 → install 顺序操作,不要在未重启的情况下直接
    覆盖 penmount_drv.so。

  - 如果怀疑是校准或坐标转换的问题,想在 Xorg 的 log 文件中看到每一笔
    触摸座标从原始值到校准后数值的详细过程,可以把 /etc/X11/xorg.conf
    中 PenMount 的 InputDevice 区段里的

         Option "Debug" "off"

    改成

         Option "Debug" "on"

    然后重新启动 X(不需要重新启动整个系统)。开启后,驱动会在
    Xorg.0.log 中输出带有 "[calib-debug]" 字样的详细信息,包含每一笔
    触摸事件的原始座标、目前的校准模式(RAW / CALIBRATED /
    FALLBACK-STRETCH)、校准后座标,以及换算到目前屏幕分辨率后的像素
    座标。由于这些信息在每一笔触摸时都会输出,内容较多,预设为关闭,
    建议仅在排查问题时暂时开启,排查完毕后改回 "off" 并重启 X。
